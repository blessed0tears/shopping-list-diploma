# Совместный список покупок

Дипломный проект: **«Разработка информационной системы “Совместный список покупок”»**.

## Описание

Проект представляет собой веб-приложение для совместного ведения списков покупок. Пользователи могут создавать группы, приглашать участников по email, вести списки товаров и отмечать покупки в общем пространстве.

Возможности системы:

- регистрация, вход и выход пользователей;
- создание групп и списков покупок;
- добавление участников в группы по email;
- добавление, редактирование и удаление товаров;
- категории и комментарии к товарам;
- видимая история изменений товаров;
- управление ролями группы: владелец и участник;
- переименование, архивирование и удаление списков покупок;
- отметка купленных товаров;
- выбор единицы измерения из списка или ввод собственного варианта;
- светлая и тёмная тема интерфейса;
- хранение данных в SQL Server.

## Технологии

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server / LocalDB
- ASP.NET Core Identity
- Bootstrap
- Visual Studio

## Структура проекта

- `Controllers` — MVC-контроллеры приложения.
- `Models` — доменные модели и модели Identity.
- `Views` — Razor-представления.
- `Data` — контекст Entity Framework Core.
- `Services` — слой сервисов для будущей бизнес-логики.
- `ViewModels` — модели представления для страниц, форм авторизации, групп, списков и товаров.
- `wwwroot` — статические файлы: CSS, JavaScript, изображения.
- `Documentation` — материалы и документы дипломной работы, включая ER-диаграмму базы данных и пользовательскую инструкцию.
- `Migrations` — миграции Entity Framework Core для создания схемы SQL Server.

## Запуск в Visual Studio

1. Установите Visual Studio 2022 с workload **ASP.NET and web development**.
2. Убедитесь, что установлен **.NET 8 SDK** и доступен SQL Server LocalDB.
3. Откройте файл `ShoppingListDiploma.sln`.
4. Проверьте строку подключения `DefaultConnection` в `appsettings.json`.
5. Миграция `InitialCreate` уже добавлена в папку `Migrations`. Для применения миграций к локальной базе данных выполните в Package Manager Console:

   ```powershell
   Update-Database
   ```

6. Если после изменения моделей потребуется новая миграция, выполните:

   ```powershell
   Add-Migration <MigrationName>
   Update-Database
   ```

7. Запустите проект профилем `https` или `IIS Express`.

## Запуск через CLI

Если установлен .NET SDK, проект можно запустить из корня репозитория:

```bash
dotnet restore
dotnet ef database update
dotnet run
```

После запуска откройте адрес, указанный в консоли, например `https://localhost:7280`.


## Основные возможности

Реализованная функциональность совместного списка покупок:

- создание группы покупок и просмотр только тех групп, где пользователь является участником;
- добавление участника в группу по email зарегистрированного пользователя;
- создание списков покупок внутри группы;
- добавление, редактирование и удаление товаров в списке;
- отметка товара как купленного и отмена отметки;
- отображение пользователя, который добавил товар, и пользователя, который отметил товар как купленный;
- фильтрация товаров: все, купленные, некупленные;
- категории и комментарии к товарам;
- просмотр истории изменений товаров;
- управление участниками владельцем группы;
- архивирование и удаление списков покупок;
- выпадающий список единиц измерения с возможностью указать свой вариант;
- переключатель светлой и тёмной темы с сохранением выбора в браузере.

## Авторизация

В проекте настроена ASP.NET Core Identity. Пользователь может зарегистрироваться, войти в аккаунт и выйти из него через ссылки `Регистрация`, `Вход` и `Выход` в верхнем меню. Страницы `Группы` и `Списки` защищены атрибутом `[Authorize]` и доступны только после входа в аккаунт.

## База данных

Схема базы данных описывает пользователей Identity, группы покупателей, роли участников, списки покупок, товары с категориями и комментариями, а также историю изменений товаров. ER-диаграмма в формате Mermaid находится в файле `Documentation/er-diagram.md`.
