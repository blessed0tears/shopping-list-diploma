# Описание контроллеров приложения

## 1. Общая архитектура контроллеров

Приложение использует ASP.NET Core MVC. Контроллеры принимают HTTP-запросы, выполняют валидацию, проверяют доступ текущего пользователя, работают с `ApplicationDbContext` и возвращают Razor Views или перенаправления.

## 2. HomeController

Контроллер публичных страниц.

| Action | Метод | Назначение |
| --- | --- | --- |
| Index | GET | Главная страница проекта. |
| Privacy | GET | Страница с кратким описанием проекта. |
| Error | GET | Страница ошибки. |

## 3. AccountController

Контроллер регистрации, входа и выхода пользователя через ASP.NET Core Identity.

| Action | Метод | Доступ | Назначение |
| --- | --- | --- | --- |
| Register | GET | Гость | Отображает форму регистрации. |
| Register | POST | Гость | Создаёт пользователя, выполняет валидацию формы и вход после успешной регистрации. |
| Login | GET | Гость | Отображает форму входа. |
| Login | POST | Гость | Проверяет email и пароль, выполняет вход пользователя. |
| Logout | POST | Авторизованный пользователь | Завершает пользовательскую сессию. |

### Особенности

- Для POST-форм используется antiforgery-защита.
- Для форм применяются view model с DataAnnotations.
- После успешного входа или регистрации пользователь перенаправляется на локальный `returnUrl` или на главную страницу.

## 4. ShoppingGroupsController

Контроллер групп покупок. Все действия защищены атрибутом `[Authorize]`.

| Action | Метод | Назначение |
| --- | --- | --- |
| Index | GET | Показывает только группы, где текущий пользователь является участником. |
| Create | GET | Отображает форму создания группы. |
| Create | POST | Создаёт группу и добавляет текущего пользователя как участника с ролью `Owner`. |
| Details | GET | Отображает детали группы, участников и списки покупок. |
| Edit | GET/POST | Позволяет владельцу изменить название и описание группы. |
| AddMember | POST | Добавляет зарегистрированного пользователя в группу по email. Доступно владельцу. |
| RemoveMember | POST | Удаляет участника из группы. Доступно владельцу. |

### Проверка доступа

Доступ к группе проверяется запросом по членству текущего пользователя:

```csharp
Where(group => group.Members.Any(member => member.ApplicationUserId == userId))
```

Если пользователь не является участником группы, контроллер возвращает `NotFound()`.

## 5. ShoppingListsController

Контроллер списков покупок и товаров. Все действия защищены атрибутом `[Authorize]`.

| Action | Метод | Назначение |
| --- | --- | --- |
| Index | GET | Показывает списки только из групп текущего пользователя. |
| Create | GET | Отображает форму создания списка внутри группы. |
| Create | POST | Создаёт список внутри доступной пользователю группы. |
| Details | GET | Показывает список, товары, поиск, фильтры, сортировку, суммы и историю изменений. |
| AddItem | POST | Добавляет товар в список. |
| EditItem | GET | Отображает форму редактирования товара. |
| EditItem | POST | Сохраняет изменения товара. |
| Edit | GET/POST | Переименовывает список и меняет архивный статус. |
| ToggleArchive | POST | Архивирует список или возвращает из архива. |
| Delete | POST | Удаляет список с товарами. |
| DeleteItem | POST | Удаляет товар из активного списка. |
| TogglePurchased | POST | Отмечает товар как купленный или отменяет отметку. |

### Фильтры товаров

Контроллер поддерживает фильтр `filter`:

| Значение | Описание |
| --- | --- |
| all | Все товары. |
| active | Некупленные товары. |
| purchased | Купленные товары. |

### Проверка доступа

Доступ к спискам и товарам проверяется через принадлежность списка к группе, где текущий пользователь является участником:

```csharp
Where(list => list.ShoppingGroup.Members.Any(member => member.ApplicationUserId == userId))
```

и

```csharp
Where(item => item.ShoppingList.ShoppingGroup.Members.Any(member => member.ApplicationUserId == userId))
```

## 6. Основные маршруты

| Маршрут | Назначение |
| --- | --- |
| `/` | Главная страница. |
| `/Account/Register` | Регистрация. |
| `/Account/Login` | Вход. |
| `/ShoppingGroups` | Список групп пользователя. |
| `/ShoppingGroups/Create` | Создание группы. |
| `/ShoppingGroups/Details/{id}` | Детали группы. |
| `/ShoppingLists` | Списки пользователя. |
| `/ShoppingLists/Create?groupId={id}` | Создание списка в группе. |
| `/ShoppingLists/Details/{id}` | Просмотр списка и товаров. |
