# Документация дипломной работы

В папке собраны материалы для дипломной работы **«Разработка информационной системы “Совместный список покупок”»**.

## Состав документации

- `technical-requirements.md` — цель, задачи, пользователи, функциональные и нефункциональные требования, архитектура приложения.
- `database-description.md` — описание структуры базы данных, таблиц, связей и правил удаления.
- `api-or-controllers-description.md` — описание MVC-контроллеров, основных actions и маршрутов.
- `use-case-diagram.md` — диаграмма вариантов использования в формате Mermaid.
- `er-diagram.md` — ER-диаграмма базы данных в формате Mermaid.
- `test-cases.md` — тестовые сценарии для проверки основной функциональности.
- `user-guide.md` — руководство пользователя и инструкция запуска проекта.
