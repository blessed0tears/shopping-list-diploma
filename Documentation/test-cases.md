# Тестовые сценарии

## 1. Авторизация

### TC-01. Регистрация пользователя

| Поле | Значение |
| --- | --- |
| Предусловия | Пользователь не авторизован. |
| Шаги | Открыть `/Account/Register`, заполнить имя, email, пароль и подтверждение, нажать «Зарегистрироваться». |
| Ожидаемый результат | Пользователь создан, выполнен вход, открыта главная страница или `returnUrl`. |

### TC-02. Валидация регистрации

| Поле | Значение |
| --- | --- |
| Предусловия | Пользователь не авторизован. |
| Шаги | Открыть регистрацию и отправить пустую форму или неверный email. |
| Ожидаемый результат | Форма не отправляется успешно, отображаются сообщения валидации. |

### TC-03. Вход пользователя

| Поле | Значение |
| --- | --- |
| Предусловия | Пользователь зарегистрирован. |
| Шаги | Открыть `/Account/Login`, ввести email и пароль, нажать «Войти». |
| Ожидаемый результат | Пользователь авторизован, в меню отображается email и кнопка `Logout`. |

### TC-04. Выход пользователя

| Поле | Значение |
| --- | --- |
| Предусловия | Пользователь авторизован. |
| Шаги | Нажать `Logout` в верхнем меню. |
| Ожидаемый результат | Сессия завершена, в меню отображаются ссылки `Login` и `Register`. |

## 2. Группы покупок

### TC-05. Создание группы

| Поле | Значение |
| --- | --- |
| Предусловия | Пользователь авторизован. |
| Шаги | Открыть `/ShoppingGroups`, нажать «Создать группу», заполнить название и описание, сохранить. |
| Ожидаемый результат | Создана группа, пользователь добавлен как `Owner`, открыта страница группы. |

### TC-06. Просмотр только своих групп

| Поле | Значение |
| --- | --- |
| Предусловия | Есть две группы, пользователь состоит только в одной из них. |
| Шаги | Открыть `/ShoppingGroups`. |
| Ожидаемый результат | Отображается только группа, где пользователь является участником. |

### TC-07. Добавление участника по email

| Поле | Значение |
| --- | --- |
| Предусловия | Есть группа и второй зарегистрированный пользователь. |
| Шаги | Открыть группу, ввести email второго пользователя, нажать «Добавить по email». |
| Ожидаемый результат | Пользователь добавлен в список участников группы. |

### TC-08. Повторное добавление участника

| Поле | Значение |
| --- | --- |
| Предусловия | Пользователь уже состоит в группе. |
| Шаги | Повторно добавить того же пользователя по email. |
| Ожидаемый результат | Отображается сообщение, что пользователь уже состоит в группе. |

## 3. Списки покупок

### TC-09. Создание списка внутри группы

| Поле | Значение |
| --- | --- |
| Предусловия | Пользователь является участником группы. |
| Шаги | Открыть группу, нажать «Создать список», заполнить название и сохранить. |
| Ожидаемый результат | Список создан внутри выбранной группы. |

### TC-10. Запрет доступа к чужому списку

| Поле | Значение |
| --- | --- |
| Предусловия | Есть список в группе, где пользователь не является участником. |
| Шаги | Попытаться открыть URL списка напрямую. |
| Ожидаемый результат | Список не отображается, возвращается `NotFound`. |

## 4. Товары

### TC-11. Добавление товара

| Поле | Значение |
| --- | --- |
| Предусловия | Пользователь является участником группы и открыл список. |
| Шаги | Заполнить название, количество, единицу измерения, категорию, комментарий и нажать кнопку добавления. |
| Ожидаемый результат | Товар появляется в списке, отображаются категория, комментарий и пользователь, который добавил товар. |

### TC-12. Редактирование товара

| Поле | Значение |
| --- | --- |
| Предусловия | В списке есть товар. |
| Шаги | Нажать «Редактировать», изменить данные, сохранить. |
| Ожидаемый результат | Данные товара обновлены. |

### TC-13. Удаление товара

| Поле | Значение |
| --- | --- |
| Предусловия | В списке есть товар. |
| Шаги | Нажать «Удалить» и подтвердить действие. |
| Ожидаемый результат | Товар удалён из списка. |

### TC-14. Отметка товара как купленного

| Поле | Значение |
| --- | --- |
| Предусловия | В списке есть некупленный товар. |
| Шаги | Нажать «Отметить». |
| Ожидаемый результат | Товар получает статус «Куплено», отображается пользователь, отметивший покупку. |

### TC-15. Фильтрация товаров

| Поле | Значение |
| --- | --- |
| Предусловия | В списке есть купленные и некупленные товары. |
| Шаги | Переключить фильтры «Все», «Некупленные», «Купленные». |
| Ожидаемый результат | Таблица отображает товары согласно выбранному фильтру. |

### TC-16. Просмотр истории изменений

| Поле | Значение |
| --- | --- |
| Предусловия | В списке выполнены действия с товарами. |
| Шаги | Открыть страницу списка и перейти к блоку «История изменений». |
| Ожидаемый результат | Отображаются дата, пользователь, тип действия, старое и новое значение. |

### TC-17. Ограничение управления участниками для роли «Участник»

| Поле | Значение |
| --- | --- |
| Предусловия | Пользователь имеет роль «Участник», но не «Владелец». |
| Шаги | Попытаться добавить или удалить участника через интерфейс или прямой POST-запрос. |
| Ожидаемый результат | Кнопки управления не отображаются, прямой запрос получает отказ в доступе. |

### TC-18. Архивирование списка

| Поле | Значение |
| --- | --- |
| Предусловия | Есть активный список покупок. |
| Шаги | Открыть список и нажать «Архивировать». |
| Ожидаемый результат | Список переносится в архив, товары доступны для просмотра, добавление и редактирование отключены. |
