# Описание базы данных

## 1. Назначение базы данных

База данных хранит сведения о пользователях, группах покупок, участниках групп, списках покупок, товарах и истории действий с товарами. Доступ к данным приложения строится вокруг членства пользователя в группе: пользователь может видеть только группы, списки и товары, связанные с группами, где он является участником.

## 2. Используемые технологии

- Entity Framework Core — ORM для работы с базой данных.
- SQL Server / LocalDB — СУБД для локальной разработки.
- ASP.NET Core Identity — стандартная подсистема учётных записей, паролей и аутентификации.
- `ApplicationDbContext` — контекст EF Core, наследующийся от `IdentityDbContext<ApplicationUser>`.

## 3. Структура базы данных

Структура базы данных состоит из таблиц ASP.NET Core Identity и таблиц предметной области приложения.

## 4. Основные таблицы предметной области

### 4.1. AspNetUsers

Таблица ASP.NET Core Identity для хранения пользователей. Расширена пользовательской моделью `ApplicationUser`.

| Поле | Тип | Описание |
| --- | --- | --- |
| Id | string | Первичный ключ пользователя. |
| UserName | string | Имя пользователя Identity. В проекте совпадает с email. |
| Email | string | Email пользователя. |
| DisplayName | string | Отображаемое имя пользователя. |
| CreatedAtUtc | DateTime | Дата создания пользователя в UTC. |

### 4.2. ShoppingGroups

Группы совместных покупок.

| Поле | Тип | Описание |
| --- | --- | --- |
| Id | int | Первичный ключ группы. |
| Name | string | Название группы. |
| Description | string? | Описание группы. |
| OwnerId | string? | Внешний ключ на владельца группы в `AspNetUsers`. |
| CreatedAtUtc | DateTime | Дата создания группы в UTC. |

### 4.3. GroupMembers

Связующая таблица пользователей и групп.

| Поле | Тип | Описание |
| --- | --- | --- |
| Id | int | Первичный ключ записи членства. |
| ShoppingGroupId | int | Внешний ключ на группу. |
| ApplicationUserId | string | Внешний ключ на пользователя. |
| Role | string | Роль участника в группе, например `Owner` или `Member`. |
| JoinedAtUtc | DateTime | Дата добавления участника в UTC. |

Для пары `ShoppingGroupId` и `ApplicationUserId` настроен уникальный индекс, чтобы пользователь не мог быть добавлен в одну группу несколько раз.

### 4.4. ShoppingLists

Списки покупок внутри группы.

| Поле | Тип | Описание |
| --- | --- | --- |
| Id | int | Первичный ключ списка. |
| ShoppingGroupId | int | Внешний ключ на группу. |
| Name | string | Название списка. |
| IsArchived | bool | Признак архивного списка. |
| CreatedAtUtc | DateTime | Дата создания списка в UTC. |

### 4.5. ShoppingItems

Товары внутри списка покупок.

| Поле | Тип | Описание |
| --- | --- | --- |
| Id | int | Первичный ключ товара. |
| ShoppingListId | int | Внешний ключ на список. |
| Name | string | Название товара. |
| Quantity | decimal | Количество товара. |
| Unit | string? | Единица измерения. |
| IsPurchased | bool | Признак купленного товара. |
| CreatedAtUtc | DateTime | Дата добавления товара в UTC. |
| PurchasedAtUtc | DateTime? | Дата отметки товара как купленного. |
| CreatedByUserId | string? | Пользователь, добавивший товар. |
| PurchasedByUserId | string? | Пользователь, отметивший товар как купленный. |

### 4.6. ItemHistories

История действий с товарами.

| Поле | Тип | Описание |
| --- | --- | --- |
| Id | int | Первичный ключ записи истории. |
| ShoppingItemId | int | Внешний ключ на товар. |
| ApplicationUserId | string? | Пользователь, выполнивший действие. |
| Action | string | Тип действия: `Created`, `Updated`, `Purchased`, `PurchaseCanceled`. |
| OldValue | string? | Старое значение. |
| NewValue | string? | Новое значение. |
| CreatedAtUtc | DateTime | Дата действия в UTC. |

## 5. Основные связи

| Связь | Тип | Описание |
| --- | --- | --- |
| ApplicationUser → GroupMembers | 1:N | Один пользователь может быть участником нескольких групп. |
| ShoppingGroup → GroupMembers | 1:N | Одна группа содержит нескольких участников. |
| ShoppingGroup → ShoppingLists | 1:N | Одна группа содержит несколько списков покупок. |
| ShoppingList → ShoppingItems | 1:N | Один список содержит несколько товаров. |
| ShoppingItem → ItemHistories | 1:N | Один товар может иметь несколько записей истории. |
| ApplicationUser → ShoppingItems | 1:N | Пользователь может добавлять и покупать товары. |

## 6. Правила удаления

- При удалении группы каскадно удаляются участники группы и списки покупок.
- При удалении списка каскадно удаляются товары списка.
- При удалении товара каскадно удаляется история действий по товару.
- При удалении пользователя ссылка на владельца группы и автора истории может быть обнулена, где это предусмотрено настройками EF Core.
