# Руководство пользователя и инструкция запуска

## 1. Назначение системы

Информационная система **«Совместный список покупок»** предназначена для совместного ведения списков покупок. Пользователи могут создавать группы, добавлять участников, создавать списки внутри групп и управлять товарами.

## 2. Инструкция запуска в Visual Studio

### Требования

- Visual Studio 2022.
- Workload **ASP.NET and web development**.
- .NET 8 SDK.
- SQL Server LocalDB или доступный SQL Server.

### Шаги запуска

1. Открыть файл `ShoppingListDiploma.sln` в Visual Studio.
2. Проверить строку подключения `DefaultConnection` в `appsettings.json`.
3. Открыть **Package Manager Console**.
4. Применить миграции:

   ```powershell
   Update-Database
   ```

5. Выбрать профиль запуска `https` или `IIS Express`.
6. Запустить проект кнопкой **Start**.
7. Открыть приложение в браузере, если оно не открылось автоматически.

## 3. Инструкция запуска через CLI

Если установлен .NET SDK и EF Core CLI, из корня репозитория выполнить:

```bash
dotnet restore
dotnet ef database update
dotnet run
```

После запуска открыть адрес из консоли, например `https://localhost:7280`.

## 4. Регистрация

1. Нажать ссылку `Register` в верхнем меню.
2. Заполнить имя пользователя, email, пароль и подтверждение пароля.
3. Нажать «Зарегистрироваться».
4. После успешной регистрации пользователь автоматически входит в систему.

## 5. Вход и выход

### Вход

1. Нажать `Login`.
2. Ввести email и пароль.
3. При необходимости отметить «Запомнить меня».
4. Нажать «Войти».

### Выход

1. Нажать `Logout` в верхнем меню.
2. После выхода в меню снова отображаются ссылки `Login` и `Register`.

## 6. Работа с группами

### Создание группы

1. Открыть раздел `Группы`.
2. Нажать «Создать группу».
3. Ввести название и описание.
4. Нажать «Создать».

После создания пользователь автоматически становится участником группы с ролью `Owner`.

### Просмотр групп

В разделе `Группы` отображаются только те группы, где текущий пользователь является участником.

### Добавление участника

1. Открыть страницу группы.
2. В блоке «Добавить участника» ввести email зарегистрированного пользователя.
3. Нажать «Добавить по email».
4. Если пользователь найден и ещё не состоит в группе, он появится в списке участников.

## 7. Работа со списками покупок

### Создание списка

1. Открыть страницу группы.
2. Нажать «Создать список».
3. Ввести название списка.
4. Нажать «Создать список».

### Просмотр списков

- Списки группы отображаются на странице группы.
- Общий раздел `Списки` показывает списки только из групп, где текущий пользователь является участником.

## 8. Работа с товарами

### Добавление товара

1. Открыть список покупок.
2. Ввести название товара.
3. Указать количество и единицу измерения.
4. Нажать кнопку добавления.

После добавления в таблице отображается пользователь, который добавил товар.

### Редактирование товара

1. Нажать «Редактировать» рядом с товаром.
2. Изменить название, количество или единицу измерения.
3. Нажать «Сохранить».

### Удаление товара

1. Нажать «Удалить» рядом с товаром.
2. Подтвердить удаление в браузерном диалоге.

### Отметка товара как купленного

1. Нажать «Отметить» рядом с товаром.
2. Товар получит статус «Куплено».
3. В колонке «Купил» отобразится пользователь, который отметил товар как купленный.

Повторное нажатие на кнопку статуса отменяет отметку покупки.

## 9. Фильтрация товаров

На странице списка доступны фильтры:

- `Все` — отображает все товары.
- `Некупленные` — отображает только товары без отметки покупки.
- `Купленные` — отображает только купленные товары.

## 10. Ограничения текущей версии

- Добавить в группу можно только уже зарегистрированного пользователя.
- Удаление групп и списков через интерфейс пока не реализовано.
- Роли участников заложены в модели, но расширенное управление правами пока не реализовано.
